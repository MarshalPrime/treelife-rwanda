# Identifiers

Primary keys are UUIDs generated by the application. People in the field see a public code: `SITE`, `TREE`, `BATCH`, or `EVT`, then the year, then six characters. The code is allocated by the server and is not accepted from the client, so two devices cannot choose the same visible code.

`client_request_id` is optional and unique. It exists so a retry of the same submission does not create a second record. The first body wins. A later submission with the same id does not overwrite the first.

`external_id` is a separate nullable column on organizations, sites, trees, and batches. It is reserved for an identifier owned by another system. The application does not interpret it as an FMES id and does not synchronize it.
